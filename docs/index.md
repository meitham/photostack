# PhotoStack

PhotoStack provides reproducible command-line steps for working with a
sequence of still-life photographs. It extracts embedded RAW previews, fixes
EXIF orientation, creates review sheets, and combines selected frames through
averaging or layer blends.

The sequence selection and artistic decisions remain manual. PhotoStack does
not recognize a subject or decide which rotations belong in the final image.

Start with the [workflow guide](getting-started/workflows.md), then consult
the [command reference](cli/index.md).
